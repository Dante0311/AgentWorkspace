## 1 被测客户端和模型

客户端也称 Harness，指 Codex CLI、Claude Code CLI、CodeBuddy CLI。它与负责执行、复核的 Codex 会话不是同一项配置。

一轮指一次原生模型执行轮次，包括消息或巡检触发的轮次；一轮可能包含多次 API 请求和工具调用。两轮只够初次连通，不能代表完整验收预算。若计费无法实时观测，我们不能精确按金额截停，需要总轮次上限；条件不足时先说明，不擅自消耗。

执行约定：先做最多两轮短任务，再在已授权总上限内逐组扩展；不自动切换服务或更贵模型；默认不自动重试产生费用的任务。达到上限或消耗无法核对时停止新增任务，保存检查点，并处理本轮持续运行的组件。模型运行中的请求可能继续产生费用，不能把轮次控制当作服务商的硬金额限制。
