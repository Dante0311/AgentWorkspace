# 正常交出操作说明

本文件是操作说明，读取它不代表收到停工请求。只有已明确安排当前入口正常交出或停工时，才执行 handoff Skill；完成接手、保存检查点或结束当前轮次不是交出安排。

执行时先核对自己的资料根，按当前版本能力自动准备缺少的 worktree，再保存本轮实际文件。检查点同时交代身份、职责与工作背景，以及累计进展、决定、下一步和未知结果；平台已知的身份和位置由工具提供，业务内容由当前 Agent 补齐。具体范围见 checkpoints.md，新取回的旧文件不算本轮成果。

创建检查点后使用本入口 binding 调用 agent.stop。不要筛选或重新解释用户资产，不决定未决业务是否应该重做。stop 返回等待 idle 后，结束本轮，不继续业务；运行器会确认停妥并释放资格。不要自行启动下一会话。
