# Workbench 0.4

本页描述当前本机工作台的真实实现范围。它是 AgentWorkspace 公共操作的图形入口，不是另一套身份、状态机或聊天客户端。

## 信息架构

工作台采用六个管理视图：

- **Agent**：持久身份、本机实例目录、当前 Binding、原生会话、运行器和自动收件分别展示。
- **协作**：正式 Message、ACK 状态、Work 与 Delivery。发布成功不表示接收者已读，ACK 不表示业务完成。
- **共享资料**：按固定 Workspace Git revision 读取共同资料，列出和采用共享 Skill；不构造插件市场或虚拟文件树。
- **管家**：读取真实 Steward、Sentinel、Maintainer 登记，管理显式授权、巡检计划和限定维修。
- **Workspace**：展示逻辑 Locator、访问地址、共享 revision、本机观测时间及产品/好友关系。
- **操作与恢复**：核对已有 Message operation、transfer 和健康报告。结果未知时沿用原 ID，不重放副作用。

“普通会话”保持独立入口。它不创建持久 Agent、Binding、Message/ACK 或交接保证。

## 状态依据

`/api/state` 是只读投影，不授予执行权。每次读取都标明：

- Workspace 共享 Git revision；
- 当前安装 ID 和本机观测时间；
- 本机 registry 登记的实例目录；
- 可读时的真实 Binding、runtime 和 watch 记录；
- 不可读时的具体 `unknown_reason`，而不是伪造“离线”。

所有写操作继续通过公共 command map，后端重新核对 Binding、revision、授权和请求 ID。页面按钮和成功提示不能覆盖平台事实。

## 实例目录

创建普通 Agent 时，页面默认：

```text
AW_HOME/instances/<workspace>/<agent-id>
```

用户可以改为任意有效的本机绝对路径，包括另一磁盘。目录是该安装位置的实例副本，不进入共享身份，也不改变实例分支或当前 Binding。目标必须为空目录；写入先在同级临时目录完整准备，再原子发布。

首次创建 Workspace 时，Steward、Sentinel、Maintainer 分别选择目录。创建 receipt 保存实际三条路径；部分成功后必须用同一地址、方式和目录继续，不自动迁移、复制或重建已完成实例。接入已有 Workspace 不补建管家，用户再为明确实例准备目录。

## 部分成功和恢复

Agent 创建按“身份与目录 → 配置 → 可选进入”组合。后续配置或进入失败时，已创建身份和目录保留，结果明确返回失败步骤，不从头创建第二个实例。

Message 在发出网络请求前固定 request ID 和参数，并保存于当前浏览器标签页。响应丢失后：

1. “查看原请求”只读查询 operation；
2. “继续原请求”只发布尚未落盘的同一请求，或补齐其 publication receipt；
3. 不生成新 Message ID，不自动改用新的 Binding；
4. 本页记录移除不撤回服务端事实。

Transfer、doctor 和限定维修同样只消费真实记录。提交输入、切换配置和维修表单在响应丢失后沿用原请求 ID；已有停止请求可从运行详情或健康报告继续确认，固定原 Binding 和检查点，不启动新的模型工作。Skill 更新中断时可继续原版本，即使共享来源随后已有更新。工作台没有虚构的统一完成账本。

## 配置和桌面组织

Codex CLI 与 Codex Desktop 要求明确填写模型 ID 和推理强度；Claude/CodeBuddy 可按原生服务能力填写。保存配置不启动模型，活动实例更换配置必须走交接。非本机 HTTP 需要当前配置的明确确认，地址或 Harness 改变后页面清除确认。

“目录与桌面组织”只保存本机项目名称、Codex 分区和产品目录引用。保存引用不代表原生项目、分区或会话已创建；“发现并复用 Codex 项目”列出主目录匹配的已有项目，用户确认后保存实际项目 ID；可选择已有分区或按接口能力准备建议分区。该操作不创建聊天；实际接口缺失时返回手动补齐要求。

## 可访问性和响应式

主导航、详情页签、弹窗、焦点循环和关闭后焦点返回支持键盘操作。移动端使用单列内容和可展开导航，表单控件保持触控尺寸；系统启用减少动画时不增加动效。正式可访问性仍需在目标浏览器和屏幕阅读器中实机验收。

## 验证边界

开发回归覆盖目录选择、可恢复创建、状态投影、公共 HTTP/CLI 合同、Message 响应丢失、授权、健康报告、共享资料、Skill、桌面引用、窄屏布局和 wheel 资源。测试夹具不代表真实模型、账号、生产 Git、原生 Desktop 或屏幕阅读器已验收。
