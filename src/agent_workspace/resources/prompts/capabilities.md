# 当前版本支持范围

这是当前安装的 AgentWorkspace 的能力说明，不是执行授权，也不代表上游产品永久没有相应接口。设计中的目标不等于本版本已支持。

## 状态怎么读

- **已实现，待实机验收**：已有代码和开发测试，仍须验证用户的账号、模型服务和运行环境。
- **当前不支持**：本版未提供该操作。不是断网、待登录或临时故障；不要靠反复重试、维修或换一个名字绕过。
- **待确认**：接口、认证或实际服务能力尚未验证。既不能保证可用，也不能断言不可能支持。

## Harness 和模型

| 入口 | 已提供的能力 | 当前不支持 / 待确认 |
| --- | --- | --- |
| Codex 受管 CLI（`codex`） | 自动创建、持续通信、normal/insert、三种受管 CLI 之间自动交接、模型/强度元数据查询 | 真实账号、自有 API 的模型与强度效果待实机验收 |
| Claude Code 受管 CLI/SDK（`claude`） | 自动创建、持续 normal 通信、三种受管 CLI 之间自动交接、模型/强度元数据查询 | 本版不支持 insert/steer；真实模型服务待实机验收 |
| CodeBuddy 受管 CLI/SDK（`codebuddy`） | 自动创建、持续 normal 通信、三种受管 CLI 之间自动交接、独立模型服务配置 | 本版不支持 insert/steer 和模型/强度目录查询；可按服务说明手工填写，不代表已验证 |
| Codex Desktop（`desktop`） | 已有指定桌面控制连接的绑定、状态与通知代码，实际接口待实机确认 | 本版不支持完整自动创建及自动跨端交接；打开深链不算创建成功 |
| Claude Code / WorkBuddy Desktop | 安装位置发现 | 本版未接入自动创建、持续投递与停止观测；上游接口是否满足要求仍待确认，CLI 不能冒充 Desktop |
| 手动入口（`manual`） | 用户打开真实会话后手动绑定、handoff/relay、主动 receive | 本版不提供自动创建、自动推送或平台验证的原生停工观测 |

模型供应商与 Harness 是两回事。已配置 URL、模型、推理强度或已登录，不等于服务兼容或调用成功；自有服务不套用官方账号的模型目录。支持查询时使用实际返回值，不支持查询时不编造候选。自动交接当前只接受 `codex`、`claude`、`codebuddy`，不能静默替换用户选择的入口、模型服务或凭据。

## 用户与 Agent 遇到限制时

先核对目标实例当前 Binding 与所需操作，不从模型名称或安装位置推断能力。仅停止不支持的动作，说明具体限制和可选路径；更换 Harness、投递方式或模型服务须依据用户明确选择，不因为发现限制就中断无关工作。

`delivery_unsupported` / `insert_not_supported` 表示本版接入不支持 insert。队头和原记录保留，不改成 normal、不中断并重开轮次、不创建副本、不越过队头或伪造 ACK。需要时由用户决定主动接收原消息或在支持的入口交接后继续。普通 handoff 在 SDK 入口等待空闲，不是 insert。

`catalog=unsupported` 表示未提供目录查询；`unchecked`、`unconfirmed`、`capability_unconfirmed` 表示未验证。缺程序、缺凭据和连接故障应按实际原因处理，不一律说成“不支持”。管家不得把明确不支持的操作当成反复重启可修复的故障，也不能为补能力擅自安装插件、修改全局配置或扩大权限。

企业微信文本 Bridge、管家授权/巡检/有限维修已有实现，真实 Bot 和长期运行待实机验收。管家不是任意自动修复器；未知副作用不重放，不能强制接管。测试中的真实原生客户端配合回环模型夹具，不等于真实模型、原生 Desktop 或生产环境已经验收。
