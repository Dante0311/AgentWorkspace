Agent Workspace · 首次配置

先准备环境，再建立身份，最后选择是否启动。检测不会安装软件或执行模型任务。

连接本机工作台

1 · 检测运行环境

只检查 PATH 和部分标准安装位置；未发现不等于未安装，发现也不等于已登录。安装后重新打开工作台，或重新检测。

2 · 创建或接入 Workspace

需要 Git。远端仓库请自行准备专用私有空仓；凭据使用本机 Git 配置，不在此填写密码或 Token。仅本机存储不代表模型调用离线。

“检查访问”只读，不验证写权限。点击创建后才写入仓库和三个实例；遇到部分失败，用原简称、地址和方式继续。

3 · 配置实例的模型运行环境

可配置 Codex CLI、Claude Code CLI 与 CodeBuddy Code CLI。后两者需要对应 SDK 可选依赖；原生 Desktop 单独配置和验收，CLI 不能冒充 Desktop。创建管家身份不等于巡检正在运行。

自有服务须匹配 Harness 原生协议，Codex 使用 Responses；这里不做协议转换。环境变量必须在启动工作台的进程中可用，不会写入共享仓。此处不会修改用户全局配置。

仅此按钮会短暂启动 Codex 控制进程，不创建会话、不登录、不运行模型。自定义服务的模型目录未确认时，请自行填写原生 ID。

尚未查询能力；不会凭空生成模型或强度选项。配置保存成功不等于模型调用已验证。

保存失败会列出已完成的实例，不撤销或覆盖其他工作。启动会话请回工作台明确操作；运行中的实例必须先交接再换配置。
