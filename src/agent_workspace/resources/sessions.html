新建普通会话

在已有目录打开原生 CLI。不需要 Workspace 或 Git，不创建持久 Agent、管家或专属项目。

聊天和历史留在原生终端，不是工作台聊天界面；不提供平台 Message/ACK 或跨 Harness 交接。项目与用户规则仍可能被原生客户端加载，不保证角色隔离。

不复制目录、不创建 worktree、不写入 AGENTS.md。持久 Agent 的实例目录请从 Agent 入口进入。

Codex 使用 Responses；Claude 使用 Messages；CodeBuddy 按其原生协议。不会转换协议或自动追加 URL 后缀。

请在实际原生终端环境设置该变量。macOS Terminal 或已有终端服务不一定继承工作台的临时环境变量；缺少凭据会在调用前停止，不自动登录。

默认从 PATH 发现。此交互启动器不执行 .cmd/.bat 包装，需提供真实可执行程序；不会自动安装 Harness。

点击启动后，填写的任务可能立即调用模型。权限仍由原生 CLI 交互确认，不自动启用完全访问。

原启动请求

刷新不会自动启动；重复操作沿用原请求。原生进程已启动或结果不明时不会再次打开。关闭标签页后浏览器草稿可能消失，本机请求仍保留；请记下请求 ID。此 ID 不是原生会话 ID。
